# 校历接口分析

> 抓包时间：2026-11-05（Asia/Shanghai）
> 目标：为 AHNUoHand 的「校历」功能找数据来源
> **重要提示：这个接口不是学生常用的校历入口，数据也不完整，下文第 2 节详述。**

---

## 1. 接口出处

校历数据来自**一站式服务大厅**（`ybt.ahnu.edu.cn`）里一个隐藏页面，不在 APP 的学生课表模块里：

```
/zhxyH5/static/js/pages-view-schedule-schedule.<hash>.js
  → GET /zhxyApi/applets/workhall/api/calendar?date=YYYY-MM
```

路由表里该页 `meta:{title:"校历"}`，所以它确实是学校自己的「校历」页，但：

- 它是「网上办事大厅」下的应用，**不是教务的校历**
- 该页面在 H5 底部 TabBar 里，学生日常很少会点
- 页面展示的是**日历 + 当天课程**，不是教学日历（没有教学周安排、没有开学/放假通知）

---

## 2. 这个接口的问题（重点）

### 2.1 节假日靠 `remark` 字段，语义不明确

真实返回（2026-10）：

```json
{
  "exactDate": "2026-10-01",
  "flag": 1,
  "weekStr": "周四",
  "remark": "国庆节",
  "weekInt": 4
}
```

普通周末则是：

```json
{ "exactDate": "2026-10-11", "flag": 1, "weekStr": "周日", "remark": "周日", "weekInt": 7 }
```

也就是说：

| 字段 | 含义 |
| ---- | ---- |
| `flag` | `1` = 休息，`0` = 上班上课。**普通周末也是 1**，所以光看 `flag` 分不出周末和节假日 |
| `remark` | 普通周末与 `weekStr` 相同（「周六」「周日」）；节假日则是节日名（「国庆节」） |

判断节假日只能靠「`remark` ≠ `weekStr`」这个隐含约定，**没有任何字段明确标注这是节假日**。学校随时可能改这个约定而不改接口版本号，届时判断就会失效。

### 2.2 没有教学周信息

接口只给日期和休息标记，**完全没有**：

- 这是第几教学周
- 学期起止日期
- 开学日、放假安排
- 考试周

所以本项目里「第 N 教学周」不是从这个接口算的，而是取自**课程表**（见第 4 节）。

### 2.3 没有调休与补课信息

`flag` 能反映「这天休不休」，但：

- 不说明**因何而休**（除非 `remark` 恰好在节假日那几天有值）
- 不说明**调休补哪天的课**
- 不提供「补课安排」（比如「周日补周三的课」）

例如 2026-10-10（周六）`flag=0`，能知道要上课，但**上的是哪天的课无从得知**。

### 2.4 另一个接口基本不可用

原来 JS 里配套的 `GET /applets/synthesis/query/toDayClass?date=YYYY-MM-DD` 用来查当天课程，实测返回：

```json
{ "success": true, "message": "查询成功！", "code": 200, "result": { "class": null } }
```

`class` 恒为 `null`。原因是它依赖「我的课表」模块，而**该模块被学校弃用了**——`rhptTerm/get/nowTerm` 一直返回「未设置学年学期」，`get/year` 返回空数组。

所以本项目**不调用**这个接口，每天的课程直接从已读取的教务课表里按「周次 + 星期」筛。

## 3. 接口详情

基址 `https://ybt.ahnu.edu.cn/zhxyApi`，与其他 `ybt` 接口共用 CAS 令牌（`X-Access-Token`）。

### `GET /applets/workhall/api/calendar?date=YYYY-MM`

返回按 `last / now / next` 三组（上月、本月、下月）：

```json
{
  "success": true,
  "code": 200,
  "result": {
    "last":  [ { "exactDate": "2026-09-01", "flag": 0, "weekStr": "周二", "remark": "周二", "weekInt": 2 } ],
    "now":   [ { "exactDate": "2026-10-01", "flag": 1, "weekStr": "周四", "remark": "国庆节", "weekInt": 4 } ],
    "next":  [ { "exactDate": "2026-11-01", "flag": 1, "weekStr": "周日", "remark": "周日", "weekInt": 7 } ]
  }
}
```

三组都要，因为月视图首尾会用到相邻月的日期。

令牌失效时返回 `{"status":500,"message":"Token失效，请重新登录"}`。

## 4. 项目内的实现

既然校历接口给不了教学周，本项目采取**分工**：

| 数据 | 来源 |
| ---- | ---- |
| 休息日、节假日名称 | `workhall/api/calendar`（本文档的接口） |
| 首周起始日、总周数 | **课程表**（教务页面上的「起始日期」） |
| 第 N 教学周 | 由首周 + 今天推算 |
| 每天上什么课 | **课程表**缓存，按「周次 + 星期」筛 |
| 上课时间 | `periodSchedule.ts` 的作息表 |

| 文件 | 职责 |
| ---- | ---- |
| `src/lib/calendar.ts` | 接口调用、`remark` 判定节假日、月视图排布 |
| `src/lib/semesterSettings.ts` | 首周与总周数，支持手动覆盖 |
| `src/pages/CalendarPage.tsx` | 月历、节假日标注、当天课程、跳转课表 |

首周与总周数**允许手动指定**：自动读到的值不一定对，用户可在课表设置里改，校历会跟着变。

---

## 5. 作息时间（夏令时 / 冬令时）

学校一天 13 节课。两套表只差下午与晚上的钟点：

| | 夏令时（5/1–9/30） | 冬令时（10/1–4/30） |
| --- | --- | --- |
| 上午 1–5 | 08:00–12:15 | 08:00–12:15 |
| 下午 6–10 | 14:30 起 | 14:00 起 |
| 晚上 11–13 | 19:00–**21:00** | 19:00–**21:25** |

若教务页面能读到真实节次时间，则以真实值为准；读不到才用这两套默认表。

---

## 6. 限制与合规

- 依赖 `ybt` 的 CAS 令牌，与空教室共用一次登录。
- 只做查询展示，不做签到、预约或批量抓取。
- **数据仅供参考**：接口本身不提供教学周与调休补课信息，节假日的准确性取决于学校维护 `remark` 的及时程度。
- 如需权威校历，应查阅教务处发布的正式文件，本应用无法替代。
